# ชุด Template เอกสารส่วนตัว

โครงสร้าง: ชนิดเอกสาร → ชุด Template ที่ตั้งชื่อ → หัวข้อหลักและรายการย่อย

- PR เริ่มด้วยหัวข้อจัดซื้อเดิม ชนิดอื่นเริ่มว่าง
- เพิ่มชนิดเอกสารโดยระบุรหัส ASCII ไม่เกิน 10 ตัวและชื่อ เช่น `CT - สัญญา`
- เลือกชุดจาก “ชุด Template ของฉัน” เพื่อโหลดหัวข้อ เลขชุด เลขหน้า และรายการที่เลือก
- “บันทึกเป็นชุดใหม่” ต้องใช้ชื่อที่ยังไม่มีภายใต้ชนิดเอกสารนั้น
- “อัปเดตทับชุดเดิม” แก้ชุดที่เลือก โดยคงรหัสชุดเดิมไว้
- สร้างและแก้ Template ได้ก่อนเลือก PR สำหรับเอกสารจริง

`procurement-templates.php` ใช้ผู้ใช้จาก session เท่านั้น ทุกคำสั่งบันทึกตรวจ CSRF และไม่มีสิทธิ์อ่าน Template ของผู้อื่น แม้เป็นผู้ดูแลระบบ

ข้อมูลจัดเก็บใน `storage/procurement-templates/` นอก IIS document root (`app/public/`) แยกไฟล์ตาม hash ของ user ID พร้อม file lock และการเขียนไฟล์ชั่วคราวก่อนแทนที่ไฟล์เดิม บัญชี PHP/IIS ต้องเขียนโฟลเดอร์นี้ได้ และควรสำรองโฟลเดอร์นี้ร่วมกับข้อมูล storage อื่น การใช้งานหลายเว็บเซิร์ฟเวอร์ต้องใช้ storage ร่วมกัน

ตรวจสอบ:

```powershell
php scripts/test-procurement-templates.php
node scripts/test-procurement-templates-ui.cjs
node --check app/public/docMain/app.js
```
