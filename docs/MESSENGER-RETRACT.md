# ยกเลิกข้อความใน Messenger

ใช้ได้ทั้ง EIS-DOCS และ Supplies ในห้องรวม ห้องส่วนตัว และงานที่ฝากถึงทีมผู้ดูแล รวมถึงหน้ากล่องงาน Admin

1. เปิดบทสนทนาแล้วหาข้อความที่ตนเองส่ง
2. กด **ยกเลิกข้อความ** ใต้ข้อความ แล้วกดยืนยัน
3. ข้อความและรูปถูกแทนด้วย **ยกเลิกข้อความแล้ว** สำหรับทุกคนที่มีสิทธิ์ในห้อง ระบบเก็บผู้ส่ง เวลาส่ง และเวลายกเลิกไว้
4. ผู้รับออนไลน์เห็นผลผ่าน WebSocket ทันที ผู้รับออฟไลน์จะเห็นสถานะยกเลิกเมื่อกลับมาเปิดประวัติ

ยกเลิกได้เฉพาะข้อความของตนเอง ไม่มีสิทธิ์ยกเลิกข้อความของผู้ใช้อื่นแม้เป็น Admin ชื่อผู้ดูแลแต่ละชื่อแยกกัน ระบบไม่มีระยะเวลาจำกัดในการยกเลิกข้อความที่ยังอยู่ในประวัติ

สำหรับงานแจ้งเรื่อง ระบบปรับสถานะและข้อมูลคำตอบตามข้อความที่ยังอยู่ หากยกเลิกคำตอบที่ใช้ปิดงานจนไม่มีคำตอบรองรับ หรือยกเลิกคำตอบพร้อมปิดงาน ระบบเปิดงานกลับ และถอนสรุปปิดงานที่สร้างจากคำตอบนั้น เก็บเหตุการณ์ยกเลิกไว้ในประวัติงาน

หลังติดตั้ง กด Ctrl+F5 เพื่อโหลดหน้าจอรุ่นใหม่ ไฟล์ฝั่งบริการต้องโหลดใหม่ด้วยการ restart Presence service

ไฟล์หลักที่เปลี่ยน

- WebSocket-Service `chat.js`, `server.js`
- EIS-DOCS `app/public/assets/js/presence-chat.js`, `app/public/assets/css/presence-chat.css`, `app/public/docMain/message-inbox.js`, `app/public/docMain/message-inbox.php`, `app/src/Presence.php`
- Supplies `assets/js/presence-chat.js`, `assets/css/presence-chat.css`, `conf/presence/Presence.php`

ทดสอบสิทธิ์ผู้ส่ง การยกเลิกซ้ำ การเอารูปออก การตอบและปิดงาน การเก็บประวัติ การบันทึกล้มเหลว WebSocket realtime การกลับมาออนไลน์ และหน้าจอแชทกับกล่องงานแล้ว
