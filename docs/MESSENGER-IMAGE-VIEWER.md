# ดูภาพขนาดใหญ่ใน Messenger

ใช้ได้ในแชท EIS-DOCS แชท Supplies และกล่องงาน Admin

1. คลิกรูป หรือข้อความ **ดูภาพเต็มจอ ขยายภาพ** ใต้รูป
2. กด **+** เพื่อขยาย หรือ **−** เพื่อย่อ มีตัวเลขแสดงขนาดภาพเป็นเปอร์เซ็นต์
3. **พอดีหน้าจอ** ปรับให้เห็นภาพครบทั้งภาพ **100%** แสดงตามขนาดพิกเซลของรูป
4. **เต็มจอ** เปิดโหมดเต็มจอของเบราว์เซอร์ กด **ออกจากเต็มจอ** เพื่อกลับ หากเบราว์เซอร์ไม่รองรับยังดูภาพเต็มหน้าต่างได้
5. ลากด้วยเมาส์หรือนิ้วเพื่อเลื่อนภาพที่ขยาย หมุนล้อเมาส์เพื่อปรับขนาด และใช้ปุ่ม + − หรือ 0 บนคีย์บอร์ดได้
6. ดาวน์โหลดรูปได้ หรือกด **ปิด** เพื่อกลับไปที่บทสนทนา

เมื่อข้อความถูกยกเลิกหรือเซสชันสิ้นสุด ตัวดูรูปจะปิดและล้างรูปออก หลังอัปเดตให้กด Ctrl+F5 เพื่อโหลดไฟล์รุ่นใหม่
