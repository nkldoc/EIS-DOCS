# อีเมลและ PIN ในโปรไฟล์

โปรไฟล์แสดงอีเมลพนักงานและมีปุ่มแก้ไข อีเมลบันทึกใน `NMU_DATACENTER.dbo.dc_emp.c_email`

PIN ความปลอดภัยเป็นรหัสตัวเลข 6 หลัก เก็บแฮชใน `EIS_DOCS.dbo.DOCS_USER_PIN` ตั้งครั้งแรกได้จากบัญชีของตนเอง หลังตั้งแล้วแก้ไขไม่ได้ ต้องกด **ลืม PIN / ขอปลดล็อก** ในโปรไฟล์

Admin ดูคำขอจากเมนู **คำขอปลดล็อก PIN** พร้อมจำนวนคำขอรอดำเนินการ ตรวจสอบผู้แจ้งแล้วกดปลดล็อก ผู้ใช้ตั้งรหัสใหม่ได้หนึ่งครั้งโดยไม่ต้องทราบ PIN เดิม เมื่อบันทึกแล้วล็อกการแก้ไขกลับทันที เก็บประวัติผู้อนุมัติและเวลาตั้งใหม่ใน `DOCS_PIN_RESET_REQUEST`

ผู้สวมสิทธิ์ส่งคำขอหรือเปลี่ยน PIN ไม่ได้ ระหว่างรอตั้งรหัสใหม่หลัง admin ปลดล็อก PIN เดิมลงนามไม่ได้ การปลดล็อกและตั้ง PIN ใหม่ยกเลิกการยืนยันลงนามที่ค้างอยู่ด้วยเลขรุ่นของ PIN

กรอกผิด 5 ครั้งพัก 5 นาที การลงนามและบันทึกผลตรวจสอบต้องยืนยัน PIN ผ่าน PHP ก่อนเรียกบริการ PDF การลงนามหลายรายการใช้ PIN เดียวที่กรอกในรอบนั้น และตรวจสิทธิ์กับแต่ละเอกสาร

ติดตั้งบนเซิร์ฟเวอร์อื่น: รัน `016_employee_email_permission.sql`, `017_user_pin.sql` และ `018_pin_reset_requests.sql` ตามลำดับด้วย DBA แล้ว deploy PHP, JavaScript, HTML และ `app/public/web.config` ด้วยกัน IIS ต้องส่ง `/pdf/sign` และ `/api/pdf/sign` เข้า `sign-with-pin.php` และ Tomcat port 8080 ต้องเข้าถึงได้เฉพาะบริการภายใน เพื่อป้องกันการข้ามการตรวจสอบ PIN

บริการ PHP ส่งต่อ PDF API ไป `http://127.0.0.1:8080/eis-docs/api/pdf/sign` ตาม IIS configuration ของโปรเจกต์
