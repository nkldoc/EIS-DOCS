# สิทธิ์จัดทำเอกสารของหน่วยงาน

ผู้ดูแลระบบ (`i_type_user = 2`) เข้าเมนู **กำหนดสิทธิ์หน่วยงาน** หรือ `/eis-docs/docMain/department-config.php` ค้นหาชื่อ/รหัสหน่วยงานแล้วกด **เพิ่มสิทธิ์** ถอนสิทธิ์จากรายการหน่วยงานที่ได้รับสิทธิ์ได้

ระบบตรวจ `dc_cost_id` จาก session บัญชีผู้ใช้ ไม่รับรหัสหน่วยงานจากข้อมูลเอกสาร ผู้ดูแลระบบสร้างเอกสารได้เสมอ บัญชีประเภท 3 ไม่มีสิทธิ์ดูแลการตั้งค่านี้

หน่วยงานที่ยังไม่ได้เพิ่มสิทธิ์สร้างเอกสารใหม่ไม่ได้ การถอนสิทธิ์ไม่เปลี่ยนสิทธิ์เข้าถึงหรือแก้ไขเอกสารเดิมและการลงนาม

## ติดตั้งบนเซิร์ฟเวอร์อื่น

รันด้วยบัญชี DBA ตามลำดับ:

1. `database/EIS_DOCS/013_document_department_permissions.sql`
2. `database/EIS_DOCS/014_document_department_permissions_grants.sql` (เปลี่ยนชื่อ principal ถ้าไม่ได้ใช้ `eis_docs_app`)

เริ่มต้นไม่มีหน่วยงานที่ได้รับสิทธิ์ ให้ admin เพิ่มหน่วยงานที่ต้องการก่อนผู้ใช้งานสร้างเอกสารใหม่ รายชื่อค้นหามาจาก `NMU_DATACENTER.dbo.dc_cost` ที่ `i_enable=1`, `i_delete=2`, `i_last=1` จำกัดครั้งละ 50 รายการ

ตรวจสอบด้วย `php scripts/Test-DocumentCreationAccess.php` การทดสอบใช้ transaction และ rollback ข้อมูลทดสอบทั้งหมด
