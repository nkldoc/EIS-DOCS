# จัดการรายการเอกสาร

Admin (`i_type_user=2`) เข้าเมนู **จัดการรายการเอกสาร** ค้นหาชื่อเอกสารหรือเลข PR กรองใช้งาน/ยกเลิกการใช้งาน แล้วเลือกรายการได้ครั้งละ 1–100 รายการ

เปิดใช้งานและยกเลิกการใช้งานใช้ `DOCS_HDR.is_enabled` แยกจากสถานะ Workflow การยกเลิกซ่อนรายการจากหน้ารายการเอกสารและหยุดแก้ไข/บันทึกผลลงนาม เปิดใช้งานคืนจะคงผลลงนามเดิม

หน้ารายการแสดงครั้งละ 25 รายการ พร้อมจำนวนรวมและปุ่มก่อนหน้า/ถัดไป การค้นหาและตัวกรองยังคงอยู่เมื่อเปลี่ยนหน้า

การลบลบข้อมูลเอกสาร ประวัติ Workflow และการแจ้งเตือน พร้อมเอารหัสเอกสารออกจากชุดเอกสาร ชุดที่ไม่เหลือรายการจะถูกลบ ไฟล์ PDF และ JSON คู่กันภายใต้ `EIS_DOCS_PDF_STORAGE` จะถูกลบด้วย หากมีเอกสารอื่นอ้างอิงไฟล์เดียวกัน ระบบจะเก็บไฟล์ไว้

ก่อนติดตั้งบนเซิร์ฟเวอร์อื่น รัน `database/EIS_DOCS/015_document_enabled.sql` ด้วยบัญชี DBA แก้ชื่อ principal ใน GRANT ถ้าไม่ได้ใช้ `eis_docs_app`

ทดสอบด้วย `php scripts/Test-AdminDocuments.php` สร้างและล้างข้อมูลทดสอบเอง
