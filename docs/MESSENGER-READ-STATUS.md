# สถานะการอ่านและการล้างโดย Admin

“ตอบแล้ว / รอผู้ใช้” คือสถานะงานที่ Admin ตอบแล้วและรอผู้ใช้ตอบกลับ ไม่เปลี่ยนเป็นปิดงานเมื่อเปิดอ่าน

“ข้อความใหม่สำหรับคุณ” คือข้อความที่ Admin คนปัจจุบันยังไม่ได้อ่าน ส่วน “ผู้ใช้ยังไม่อ่าน” คือข้อความที่ส่งถึงผู้ใช้และยังไม่ได้อ่าน

ในกล่องงานสนทนา เปิดงานแล้วกด “ล้างสถานะผู้ใช้เป็นอ่านแล้ว” และยืนยัน ระบบล้างจำนวนข้อความถึงผู้ใช้ที่ยังไม่อ่านเป็น 0 รวมถึงผู้ใช้ที่ออฟไลน์ เก็บชื่อ Admin และเวลาที่ล้างในประวัติ ไม่ถือว่าผู้ใช้อ่านจริง และไม่ปิดงาน หากผู้ใช้เปิดอ่านจริงภายหลังจะเปลี่ยนการแสดงผลเป็น “ผู้ใช้อ่านแล้ว” ข้อความใหม่หลังล้างยังแจ้งเตือนตามปกติ

Admin ในทีมล้างงานทีมได้ ส่วนงานส่วนตัวจัดการได้เฉพาะ Admin เจ้าของบทสนทนา
