# รายงานงานสนทนารายเดือน

เปิด กล่องงานสนทนา → รายงานรายเดือน / Export Excel หรือ /eis-docs/docMain/message-report.php เฉพาะ Admin EIS-DOCS ที่ไม่ได้สวมสิทธิ์ผู้ใช้

เลือกเดือน ระบบ EIS-DOCS / SUPPLIES และสถานะ แล้วกดแสดงรายงาน ดูประวัติขั้นตอนจากปุ่มในแต่ละงาน หรือกด Export Excel (.xlsx)

ไฟล์ Excel มี 3 ชีต: สรุปงาน, ประวัติขั้นตอน, ข้อมูลรายงาน พร้อมชื่อเรื่อง ผู้แจ้ง ผู้รับผิดชอบ สถานะ เวลาแจ้งปัญหา รับปัญหา ถามกลับ รอผู้ใช้ตอบ ข้อความผู้ใช้ล่าสุด แก้ไขเรียบร้อยและปิดงาน พร้อมสรุปการแก้ไข

รวมงานที่เปิดหรือมีการดำเนินการในเดือนที่เลือก ตามเวลา Asia/Bangkok งานที่มีการติดตามข้ามเดือนอาจปรากฏในหลายเดือน ประวัติขั้นตอนแสดงทั้งเรื่องและระบุเหตุการณ์ในเดือน / นอกเดือน สถานะเป็นสถานะปัจจุบัน ณ เวลาสร้างรายงาน

เวลารับปัญหาใช้การรับงาน / รับช่วง หรือเวลาที่ Admin เริ่มตอบหากระบบรับงานอัตโนมัติ เวลาถามกลับบันทึกจากตัวเลือก “ถามกลับผู้ใช้ / ขอข้อมูลเพิ่มเติม” ในหน้าตอบงาน ตัวเลือกนี้ไม่สามารถใช้พร้อมตอบแล้วปิดงาน

งานเก่าที่ไม่ได้ระบุประเภทคำตอบไว้ไม่มีเวลาถามกลับ ส่วนการแก้ไขเรียบร้อยใช้เวลาปิดงานพร้อมสรุปการแก้ไข ไม่สร้างเวลาแก้ไขแยกย้อนหลัง เมื่อเปิดงานใหม่สถานะปัจจุบันไม่ปิด และเวลาปิดครั้งก่อนยังดูในประวัติขั้นตอนได้

งานทีมเปิดให้ทีม Admin รายงานได้ งานส่วนตัวแสดงเฉพาะ Admin เจ้าของบทสนทนา ไม่ส่งภาพแนบลง Excel
