# Admin หลายผู้ดูแล

ใช้ได้บน dev และ production ที่ตั้งค่า Presence ตามคู่มือเดิม ทั้ง EIS-DOCS และ Supplies

1. เข้าสู่ระบบด้วยบัญชีและรหัสผ่าน Admin เดิม ระบบตรวจสอบสิทธิ์ก่อนแสดงช่องชื่อ
2. กรอกชื่อผู้ดูแล เช่น `admin-eak` หรือ `admin-moo` ชื่อใช้ตัวพิมพ์เล็ก ตัวเลข `_` และ `-` โดยขึ้นต้น `admin-`
3. ผู้ดูแลชื่อแตกต่างกันใช้บัญชีเดียวกันพร้อมกันได้ ไม่แทนที่กัน
4. ชื่อเดิมที่กำลังใช้งานจะแสดงคำยืนยัน ให้แทนที่เฉพาะชื่อนั้น เปลี่ยนชื่อ หรือยกเลิก คำยืนยันมีอายุ 2 นาที
5. ใช้ชื่อเดิมเมื่อกลับมาตอบงาน เพื่อให้ตรงกับผู้รับผิดชอบและห้องส่วนตัวของตน

ชื่อจะแสดงในรายชื่อออนไลน์ ผู้ส่งข้อความ ผู้รับผิดชอบ ผู้รับช่วงงาน และผู้ปิดงาน งานทีมใน EIS-DOCS ใช้ร่วมกันได้ แต่การตอบงานที่มีผู้รับผิดชอบอื่นต้องรับช่วงก่อน ระบบตรวจเวอร์ชันเพื่อป้องกันการแก้พร้อมกัน

ชื่อผู้ดูแลเป็นชื่อระบุผู้ปฏิบัติงานภายใต้บัญชีที่ผ่านการล็อกอิน ไม่ใช่บัญชีหรือรหัสผ่านใหม่ และไม่ให้สิทธิ์ Admin เพิ่ม ผู้ใช้ทั่วไปและการสวมสิทธิ์ไม่ได้รับข้อยกเว้นนี้ Supplies ไม่ได้สิทธิ์จัดการกล่องงานของ EIS-DOCS

ชื่อผู้ดูแลผูกกับบัญชีและระบบ แชทส่วนตัวของแต่ละชื่อไม่เปิดให้ชื่ออื่นอ่านโดยอัตโนมัติ แชทส่วนตัวเก่าที่สร้างก่อนมีชื่อยังผูกกับตัวตนเดิม ไม่ย้ายเจ้าของอัตโนมัติ

ไฟล์หลัก: EIS-DOCS `app/src/Auth.php`, `SingleLogin.php`, `Presence.php`, `SuppliesLogin.php`, `app/public/login.php`; Supplies `conf/presence/{SingleLogin,Presence,SuppliesLogin}.php`, `access/confirm-login.php`, `assets/css/admin-login.css` ซึ่งเป็น CSS ของ Supplies เอง รองรับ production ต่างโดเมน

หลังติดตั้งให้ออกจากระบบและล็อกอินใหม่เพื่อระบุชื่อ ทดสอบสองเบราว์เซอร์ด้วยชื่อแตกต่างกัน แล้วทดสอบชื่อซ้ำว่ามีผลเฉพาะชื่อนั้น
